Try these quick fixes first! Most common issues can be resolved in seconds.
Popup Not Appearing / Delayed
BillFree process may be stuck or POS using wrong printer
Quick Fix
Run BillFree Reset when no popup + no print, or when only popup is slow. Double-click the BillFree Reset icon and do a test print.
What to Ask
Ask if any print is coming · Ask if popup is slow or completely absent
Non-Tech Script
"Sir/Ma'am, ek baar BillFree Reset icon ko double-click karke test print kar dijiye."
Deep Tech Note
Print coming but popup absent → wrong printer in POS settings.
Only popup slow → process buildup, BillFree Reset clears the queue.
Bill Not Delivering
Digital delivery needs internet; SMS may mean server-side ok
Quick Fix
Check internet. If SMS received → WhatsApp delay is normal, ask to wait 2-3 mins.
What to Ask
Ask if PC internet is working · Ask if SMS reached the customer
Non-Tech Script
"Internet check kar lijiye; agar SMS aa gaya hai toh WhatsApp thoda delay ho sakta hai."
Deep Tech Note
No SMS + no WhatsApp with working internet = real delivery failure → create a ticket.
SMS received = server processed it; WhatsApp delay is provider-side.
Print Not Coming
BillFree process stuck or printer config mismatch
Quick Fix
No popup and no print → run BillFree Reset.
Popup appears but no print → printer config change in POS.
What to Ask
Ask if popup appears · Ask if printer was changed recently
Non-Tech Script
"Ek baar dekhte hain popup aa raha hai ya nahi; usse exact path clear ho jayega."
Deep Tech Note
Popup yes + no print = BillFree working fine but physical printer mapping changed in POS. Needs POS-side reconfiguration.
BillFree Not Working / Service Down
Start by identifying the exact issue type
Quick Fix
Identify first: is it a popup issue, delivery issue, or print issue? Each has a different fix above.
Non-Tech Script
"Sir, exact issue samajhne ke liye ek quick check karte hain — BillFree popup issue hai, delivery issue hai, ya print issue hai?"
